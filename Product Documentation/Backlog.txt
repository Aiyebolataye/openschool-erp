## Summer School & Credit Recovery

**Status:** In Progress (frontend + docs done; backend pending)
**Module:** Academic Management / Programs & Groups / Finance
**Type:** Feature

### Summary
A paid Summer School program used for **credit recovery**: students who fail a course are flagged and can pay to enroll in a remediation group to recover the failed credit(s).

### Key flows
1. Results identify a student who failed one or more courses.
2. The student is flagged for credit recovery.
3. Institution Admin (or delegated staff) enrolls the student in a Summer School remediation group.
4. A fee plan is attached (one-time, installments, or recurring), generating an invoice.
5. The student attends and completes the course.
6. Upon completion, the failed grade is updated / credit is recovered.

### Requirements
- [x] Feature definition documented (`04 Core Platform Capabilities.txt`)
- [x] Institution Admin UI: Summer School & Credit Recovery page (`/institution/summer-school`)
  - [x] Credit Recovery tab (flagged students, failed courses, enroll action)
  - [x] Summer School Program tab (remediation groups, capacity, schedule, fee)
  - [x] Payments tab (invoices, fee plans)
  - [x] "Enroll Student" modal (course selection, dates, fee plan)
  - [x] "New Session" modal (session config, capacity, enrollment approval)
- [ ] Backend: results → auto-flag failed students
- [ ] Backend: program enrollment + capacity + waiting list
- [ ] Backend: automatic invoice generation & fee plan handling (Finance integration)
- [ ] Backend: grade/credit recovery update on completion
- [ ] Notification to parents/students when flagged and when invoice is due
- [ ] Parent/student self-service enrollment + payment (optional)

### Definition of Done
- Student failing a course appears in Credit Recovery with one-click enroll.
- Enrolling attaches a fee plan and generates an invoice automatically.
- Remediation group enforces capacity and waiting list.
- Completion updates the failed grade to "credit recovered".

## Finance: Flexible Fee Setup

**Status:** Built (frontend live)
**Module:** Finance
**Type:** Feature
